# BestShots

**Локальная программа для разбора семейного фотоархива.** Находит лучшие кадры в тысячах фото, убирает дубликаты и учится на вашем выборе. Всё работает на вашем компьютере, без облака: фото никуда не отправляются.

*English: BestShots is a local Windows app that picks the best shots from large family photo archives (aesthetics, technical quality, emotions), finds duplicates and learns from your choices. Fully offline; originals are never modified or deleted.*

Страница проекта: <https://timurnazmutdinov.github.io/BestShot/>

## Возможности

- **Отбор лучших кадров.** Фото группируются в события по дате съёмки; в каждом событии система предлагает лучшие кадры (эстетика CLIP/LAION и TOPIQ, техническое качество, эмоции и лица). Брак (смаз, тёмные, пересвет) и кадры без людей (в кадре нет лиц, и CLIP не видит людей) не предлагаются никогда; такие кадры остаются в списке, помечены и отбираются вручную. Отключается в `config.py` (`EXCLUDE_NO_PEOPLE`). Последнее слово за вами: клик по кадру — отобрать или снять.
- **Эмоции и лица.** Поиск лиц (YuNet), улыбка и моргание (MediaPipe Face Landmarker). Улыбка — только бонус: спокойные портреты не штрафуются.
- **Обучение на вашем выборе.** Личная модель (логистическая регрессия) учится на событиях, которые вы отметили «Проверено», и включается, только если угадывает лучше базовой оценки.
- **Дубликаты.** Точные копии (SHA-256) и «та же фотография» (пересохранённые, уменьшенные, повёрнутые, из мессенджеров). Серийные кадры дублями не считаются. Дубли **перемещаются** в карантин `_Дубли` с журналом и кнопкой «Вернуть»; оригиналы не удаляются никогда.
- **Большие архивы.** Анализ порциями, событие листается страницами, поиск продолжается с места остановки.
- **Экспорт.** Копирование отобранных кадров из проверенных событий в папку по годам: `ГГГГ\имя_файла`.
- **Приватность.** Работает офлайн (сеть нужна один раз для загрузки моделей), сервер слушает только `127.0.0.1`, исходные фото только читаются.

## Системные требования

Windows 10/11, Python 3.11–3.13, около 5 ГБ на диске (окружение ≈ 2 ГБ, модели ≈ 3 ГБ), 8 ГБ ОЗУ и больше; видеокарта не нужна (всё считается на CPU). Для окна приложения используется Edge WebView2 (входит в Windows 11).

## Установка (3 шага)

1. Установите Python 3.11+ с <https://www.python.org/downloads/> (отметьте «Add python.exe to PATH»).
2. Скачайте репозиторий и распакуйте (или `git clone https://github.com/timurnazmutdinov/BestShot.git`).
3. Запустите **`install.bat`** (двойной щелчок). Скрипт проверит Python, создаст `.venv`, поставит зависимости из `requirements.txt` и соберёт `BestShots.exe`.

То же вручную, PowerShell в папке проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m pip install pyinstaller
.\.venv\Scripts\python -m PyInstaller --onefile --noconsole --name BestShots --icon icon.ico launcher.py
copy dist\BestShots.exe .
```

`BestShots.exe` — тонкий запускатель: он стартует `review.py` из `.venv` и открывает окно. Без `.venv` он не работает, поэтому в репозиторий и релизы не входит: его собирает `install.bat`. `install.bat -DryRun` показывает шаги, ничего не делая.

## Запуск

Двойной щелчок по `BestShots.exe` (или `.\.venv\Scripts\python review.py` — откроется браузер; параметры `--db`, `--out`, `--port`, `--no-browser`). При первом запуске выберите главную папку с фото в панели «Папки» слева и нажмите «Анализировать новое»: нужные модели (≈ 3 ГБ) скачаются автоматически один раз, дальше всё работает без интернета. Папку экспорта можно выбрать в окне «Экспорт…» (кнопка «Сменить папку…»); выбор запоминается, внутрь главной папки с фото экспортировать нельзя. Закрытие окна останавливает сервер; если приложение уже запущено, второй экземпляр не стартует. Ошибки показываются понятным текстом, подробности — в `logs\bestshots.log`.

## Как пользоваться

1. **Папки.** Выберите главную папку с фото (подпапки любой вложенности). Цвет папки: серый — не проанализирована; синий — идёт анализ; жёлтый — проанализирована, не проверена («12 из 48»); зелёный ✓ — отработана; оранжевая точка — появились новые файлы.
2. **Дубли** (по желанию, до отбора): вкладка «Дубли» → «Найти дубли» → «Применить ко всем точным копиям», «Переместить все уверенные», неуверенные группы смотрите глазами.
3. **Анализ.** «Анализировать новое»; для больших архивов выберите порцию (500–5000) и «подряд до конца».
4. **Отбор.** Вкладка «Отбор»: события слева, кадры справа. Клик — отобрать/снять, двойной клик или Enter — просмотр, Пробел — отобрать/снять, стрелки — навигация. «✓ Проверено и дальше →» отмечает событие и открывает следующее.
5. **Экспорт.** «Экспорт…» копирует отобранные кадры **только из проверенных событий**; непроверенные — лишь отдельной кнопкой с подтверждением.
6. **Обучение.** Автоматически после экспорта или кнопкой «Обучить на моём выборе» (только по проверенным событиям).

Кнопка ⚙ показывает версию, стек технологий, модели на диске и умеет копировать сведения для отчёта об ошибке.

## Как это устроено

- **Сканирование** (`scan.py`): JPG/JPEG/PNG/HEIC и видео MP4/MOV; дата съёмки — EXIF → имя файла → дата изменения; SHA-256, ориентация, камера; события (разрыв > 3 ч) и серии (≤ 10 с); данные в SQLite. Скрытые, системные и исключённые папки пропускаются.
- **Анализ** (`analyze.py`): превью 512 px; резкость и свет (лапласиан, пересвет/провалы); эмбеддинг CLIP ViT-L/14; эстетика LAION Aesthetic v2 и pyiqa TOPIQ-IAA, техническое качество TOPIQ-NR; лица YuNet (поиск на ~2000 px) → вырезка с запасом → MediaPipe (улыбка, моргание); эмоции — CLIP zero-shot по фразам из `config.py`. Всё кэшируется по SHA-256: повторный запуск считает только новое.
- **Балл:** LAION 0.25 + TOPIQ-IAA 0.25 + TOPIQ-NR 0.15 + эмоции 0.35 (для кадров без лиц вес эмоций 0.15); веса — в `config.py`. Брак (смаз, тёмный, пересвет, TOPIQ-NR ниже порога) — жёсткий фильтр.
- **Группы похожих** внутри события (косинус CLIP ≥ 0.92 и интервал ≤ 3 мин). Рекомендация: лучший кадр группы — всегда, до 3 заметно разных кадров на группу, остальные места — по баллу до цели 38 % кадров события.
- **Личная модель** (`train.py`, `personal.py`): логистическая регрессия на признаках (CLIP→PCA 64, баллы, лица, признаки внутри группы); проверка по событиям (блоками, событие не попадает в обучение и проверку одновременно); включается только при улучшении; итог = (1 − w)·базовый + w·личный, где w = n / (n + 300).
- **Дубли** (`dupes_scan.py`, `dupes.py`): размер → SHA-256; pHash и dHash в 4 поворотах, сравнение уменьшенных 16×16 копий, дата съёмки, CLIP; пороги в `config.py` (`DUP_*`). Оригинал в группе: разрешение → EXIF → исходный формат → ранняя дата → приоритет папки → короткий путь. Видео — только точные копии; пары RAW+JPEG и одинаковые имена с разным содержимым дублями не считаются.
- **Большие архивы:** событие листается частями (по умолчанию 150 кадров, группы не режутся); анализ порциями; на ноутбуках с Modern Standby процессы просят у Windows «выполнение необходимо», чтобы не замораживаться при погасшем экране (`power.py`).
- **Интерфейс** (`review.py`): локальный `http.server` на 127.0.0.1, HTML/CSS/JS без фреймворков, окно pywebview (Edge WebView2).

## Настройка

Все пороги и веса — в [`config.py`](config.py). После правки запустите `analyze.py --score-only`: баллы, брак, группы и выбор пересчитываются за секунды.

Консольные команды работают отдельно: `scan.py <папка>`, `analyze.py [--force|--limit N|--score-only]`, `train.py`, `dupes_scan.py <папка>`.

## Приватность и безопасность

- Всё считается локально; данные хранятся в `bestshots.db` рядом с программой. Телеметрии нет.
- Сервер доступен только с `127.0.0.1`; отдаются лишь файлы из базы (по идентификатору, а не по пути).
- Исходные фото только читаются. Единственная операция, меняющая расположение файлов, — перемещение дублей в `_Дубли` по вашей команде (с журналом и возвратом). Удалять файлы из `_Дубли` нужно вручную самим.
- Фото, базы, модели и настройки в репозиторий не входят (см. `.gitignore`).
